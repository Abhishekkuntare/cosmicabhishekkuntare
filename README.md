# 🌌 Cosmic Abhishek Kuntare

> **Art • Caricature • Illustration • Creativity**

A personal artist portfolio website showcasing the creative work of **Abhishek Kuntare** — including hand-drawn sketches, caricatures, illustrations, digital artwork, reels, and creative projects.

The website is designed to bring together artwork and storytelling in a unique, modern, and visually expressive experience.

---

## 🎨 About

**Cosmic Abhishek Kuntare** is a personal creative portfolio built to showcase original artwork and artistic experiments.

The portfolio includes:

- ✏️ Hand-drawn Sketches
- 🎭 Caricature Art
- 🎨 Illustrations
- 🖼️ Digital Artwork
- 🎬 Art Reels
- 💡 Creative Projects
- 🧑‍🎨 Character Designs
- 💼 Commission Work

---

## ✨ Features

- 🖼️ Interactive artwork gallery
- 🔎 Artwork categories and filtering
- 🎭 Dedicated artwork detail pages
- ❤️ Like artwork interaction
- 🔗 One-click artwork link sharing
- 📱 Responsive design for mobile, tablet, and desktop
- 🎬 Reel showcase
- 📸 Instagram integration
- 📌 Pinterest integration
- 🔗 Linktree integration
- 💌 Contact and commission section
- 📜 Privacy Policy
- 📄 Terms & Conditions
- ✨ Smooth animations and transitions
- 🎨 Custom artistic typography
- ⚡ Fast and modern Next.js architecture
